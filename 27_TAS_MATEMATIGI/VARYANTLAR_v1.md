# 🧮 BATUPIA - Taş Matematiği & Varyantlar (M-007 Taslak)

**Toplam Taş Sayısı:** 144
**Referans:** Element Guardians Sembolleri

## 1. TEMEL ELEMENT TAŞLARI (108 Adet)
Her elementten 3 farklı alt sembol (varyant) ve her varyanttan 4'er adet bulunur.
(4 Element x 3 Varyant x 4 Adet x 3 Set = 108)

### 🔥 ATEŞ (KOR) - Kırmızı Set
- **V1 (Sarmal Alev):** Ana sembol.
- **V2 (Köz):** Parlayan kor parçası.
- **V3 (Volkanik Çatlak):** Magma akıntısı.

### 💧 SU (BAAM) - Mavi Set
- **V1 (Damla Girdabı):** Ana sembol.
- **V2 (Buz Kristali):** Keskin su formu.
- **V3 (Sis/Buhar):** Akışkan dalga.

### 🗿 TOPRAK (MAND) - Yeşil Set
- **V1 (Avatar Rünü):** Ana sembol.
- **V2 (Kristal Damar):** Toprak altı hazinesi.
- **V3 (Kaya Katmanı):** Sert sediment.

### 💨 HAVA (ZEPY) - Beyaz/Mor Set
- **V1 (Köz Spiral):** Ana sembol.
- **V2 (Şimşek Hattı):** Hızlı hava akımı.
- **V3 (Bulut Gözü):** Dingin fırtına.

## 2. RUH TAŞLARI (SPECIALS - 16 Adet)
Bunlar oyundaki "Mevsimler/Çiçekler" yerine geçer.
- **Kor'un Asası (4 Adet)**
- **Baam'ın İncisi (4 Adet)**
- **Mand'ın Çekici (4 Adet)**
- **Zepy'nin Yelpazesi (4 Adet)**

## 3. MÜHÜR TAŞLARI (ELITE - 20 Adet)
- **Stonebreaking Logosu (4 Adet)**
- **Altın Kolye (4 Adet)**
- **Batupia Amblemi (12 Adet - Joker/Bonus)**
